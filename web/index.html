How to use delivery admin

1. Import an order

  1. Sign in with the Easy Mandi admin password.
  2. Open an order from Easy Mandi admin or paste its order ID, then choose Import order. The server copies its customer, address, items and map pin when supplied.
  3. For a manual cart, upload or paste JSON, enter a unique reference, customer name, mobile and address, then choose Create from pasted/uploaded cart.

Manual carts contain items and quantities; payment amounts are not imported.

2. Assign and send the code

  1. Create a delivery person account with a name, mobile and password of at least 12 characters. Share credentials privately.
  2. Choose a delivery person on an order and select Assign.
  3. Select Issue customer code. Open the WhatsApp link and send the prepared message yourself.

The code expires in 24 hours. Issuing a new code invalidates the previous code. The customer shares it only after receiving the order.

3. Complete and track delivery

  1. The delivery person signs in to the partner app, marks pickup, then out for delivery.
  2. At handoff, the partner enters the customer's six-digit code to confirm delivery.
  3. Refresh to see status changes and inbox notifications. Use Show full order details for the cart and delivery history.
  4. Choose Lock when finished. Customer tracking is also available in the Easy Mandi app.

Notifications appear in the apps after refreshing; SMS and push alerts are not sent automatically.

Notifications: While signed in, updates refresh every five minutes. New updates appear automatically without clicking Refresh or re-entering a password. Unread entries are highlighted. Use Mark as read or Mark all as read; each account sees its own updates. Android users can open My deliveries or the partner jobs screen. Handoff codes are sent separately by the admin.
